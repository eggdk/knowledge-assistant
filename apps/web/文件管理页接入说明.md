# 本地知识库文件管理

管理入口为 `/files.html`。页面调用仓库已有的 Python 后端，知识库、原文件和版本保存在后端 SQLite 中；刷新页面或重启服务后仍保留。不需要模型 API Key。

## 启动

需要 Python 3.12、Node.js 和 pnpm。已准备好项目根目录的 `.venv/` 并安装依赖时，分别在两个终端中运行：

```powershell
# 从 knowledge-assistant/ 根目录启动后端
Set-Location .\apps\api
& ..\..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

```powershell
# 从 knowledge-assistant/ 根目录启动前端
Set-Location .\apps\web
pnpm.cmd dev --port 5173 --strictPort
```

打开 [文件管理页](http://127.0.0.1:5173/files.html)。如果已有服务占用相同端口，先直接访问页面，避免重复启动。各终端按 `Ctrl+C` 停止自己启动的服务。

新环境需先安装 Python 3.12，并在项目根目录创建和安装独立环境：

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r .\apps\api\requirements.txt
```

前端依赖在 `apps/web/` 中执行 `pnpm.cmd install --frozen-lockfile` 安装，版本由锁文件固定。

默认数据库为仓库根目录的 `storage/knowledge.sqlite3`；使用已有的 `KNOWLEDGE_ASSISTANT_DB` 环境变量可切换数据库。运行数据与虚拟环境均已忽略，不提交 Git。本次未修改后端行为或数据库结构。

## 使用流程

1. 页面读取真实知识库列表；没有知识库时先创建。
2. 在当前知识库中添加 UTF-8 的 MD/TXT 文件，或者选择目录后勾选其中的 MD/TXT 文件。每批最多 20 个，单文件最多 5 MiB。
3. 等待后端处理，查看逐文件结果。部分文件失败不影响成功项；失败文件不伪装成已保存记录。
4. 列表中的“可检索”来自后端当前版本的 `searchable` 字段。“待建立文本块”表示文件已保存，但当前版本缺少当前策略的文本块，可重新导入或按后端升级说明重建。
5. 同路径文件可再次上传：内容未变化时跳过，内容变化且处理成功时更新版本。失败更新不会覆盖旧的可用版本。
6. 刷新页面后仍读取后端保存的数据。选中的知识库通过 URL 的 `kbId` 保留；管理页和问答演示页之间跳转使用同一 ID。

点击“前往问答演示”后，可通过右下角插件检索本知识库。未配置模型密钥时显示检索原文和“尚未生成答案”，不会假装已经生成回答。

## 当前边界与异常

- 后端仅支持 MD/TXT 内容解析。Word、PDF、Excel 会明确提示暂不支持，不能用扩展名校验代替真实解析。
- 后端没有删除接口，删除按钮禁用；原文下载和预览也未提供。
- 文档列表接口没有文件大小字段，页面显示“—”，详情注明“后端暂未提供”。
- 后端不可用时显示连接错误并禁用创建/上传，不会回退到演示数据。启动服务后点击“重试”或“刷新列表”。
- 上传中会显示实际等待状态并禁止重复提交。若请求超时或中断，请先刷新列表核对，避免重复操作；若导入已完成但列表刷新失败，会单独提示。
- Vite 开发服务和生产预览均将 `/api` 代理至本机 8000 端口。生产预览需先 `pnpm.cmd build`，再 `pnpm.cmd preview --port 4173 --strictPort`；这不代表已部署到线上。

## 前端模块与检查

代码集中在 `src/features/file-management/`：`page.tsx` 管理页面与读取状态，`import-dialog.tsx` 负责选文件和逐文件导入结果，`api.ts` 封装真实请求与响应校验，`model.ts` 和 `types.ts` 定义前端校验及视图模型，`components.tsx` 提供共用弹窗、图标与检索状态标签。样式只由管理页入口加载。

在 `apps/web/` 运行 `pnpm.cmd typecheck`、`pnpm.cmd build`、`node --check public/embed.js` 和 `node scripts/check-embed.mjs`。模拟宿主检查不能代替真实浏览器验收；目录选择器的嵌套路径操作仍需在具体浏览器验证。

前端提供的接入方式及调用字段见 [前端接口说明](前端接口说明.md)，后端权威契约见 [知识库接口文档](../../docs/api/knowledge-base-v1.md)。本次提交不包含验收截图、测试资料或运行数据库。
