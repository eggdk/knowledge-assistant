# 第 10 课：第一次真实千问联调

更新于 2026-11-04。这个小实验只使用仓库内已标注来源的公开 Agent Insight 文档。默认测试三题：T04（辨别 Trace 超时的含义）、D03（按顺序说明评测集创建步骤）、N04（资料中没有的月费问题，应说明无法确定）。最多产生三次模型请求，每次回答最多 600 Token。

## 先检查，不花模型费用

在仓库的 `apps/api` 目录运行：

```powershell
& ..\..\.venv\Scripts\python.exe -m app.live_smoke --dry-run
```

你应看到三道题各自检索到的片段数量。`--dry-run` 不请求千问，也不会要求输入密钥。

## 再做真实调用

确认百炼 API Key 属于**按量付费模型 API**，并查看密钥管理页右上角地域。真实联调脚本会让你选择北京、新加坡、美国或中国香港，并在本次进程内使用对应的[官方接入地址](https://help.aliyun.com/zh/model-studio/base-url)。其他地域需先在当前终端设置对应业务空间的 `DASHSCOPE_BASE_URL`。地域必须与密钥一致。

在同一目录运行：

```powershell
& ..\..\.venv\Scripts\python.exe -m app.live_smoke
```

终端先提示选择地域，再提示输入 Key。粘贴时输入内容不会显示，也不会写入命令历史或仓库。程序只在本次 Python 进程内使用 Key，结束后清除。**不要把 Key 发到聊天、截图或 GitHub。** 若已经在当前终端配置 `DASHSCOPE_API_KEY`，程序会使用该环境变量，不再提示输入。

每题会打印模型状态、答案、引用的文件和行号、供应商返回的 Token 使用量，以及人工对照用的参考文本。结果保存到仓库忽略的 `storage/qwen-smoke-*.json`，不包含 Key。你可以把这个报告路径告诉我，我会直接读取并分析；若不在同一台电脑，可只分享报告内容。

## 怎样判断首轮表现

- **T04：**应说明“Trace 超时”表示一段时间没有新数据，不能直接断言 Agent 执行失败；引用应指向 `view-traces.md` 中支持该结论的行。
- **D03：**应说明先定义评测集，再维护或录入数据项；引用应指向 `datasets.md`。
- **N04：**文档没有给出供应商按月收费价格，应明确说明无法从资料确定，不应编造金额。

遇到 HTTP 401 先检查 Key 类型与地域；HTTP 429 通常与调用额度或限流有关；其余错误把**错误码和报告路径**发给我，不要发 Key。可参考[百炼错误码文档](https://help.aliyun.com/zh/model-studio/error-code)。这三题只做连通性和初步质量判断；要决定是否长期使用该模型，还需要扩大到已标注的全部题目并人工核对答案。
