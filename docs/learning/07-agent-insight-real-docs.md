# 第 7 课：用 Agent Insight 原文检查检索基线

上一课的资料是我们编写的虚构示例；这一次用公开 Agent Insight 用户指南原文。课程任务只指定了要集成 Agent Insight，没有给仓库链接。我们暂选 openEuler 的[公开 GitHub 镜像](https://github.com/openeuler-mirror/agent-insight)，并将四篇文档固定到提交 `bfdd20131330c495707220dc11d7facc9795a3b4`。来源、SHA-256 和 MIT 许可都见 [`evals/agent_insight/SOURCE.md`](../../evals/agent_insight/SOURCE.md)。如果老师以后提供特定版本，要换资料重测，不能把这份镜像自动当成老师指定版本。

## 怎么跑

从仓库 `apps/api` 目录执行：

```powershell
& ..\..\.venv\Scripts\python.exe -m app.evaluation --dataset ..\..\evals\agent_insight
```

程序只导入 `evals/agent_insight/docs/` 中的四篇原文。题目和标注留在目录外面，不会“泄露答案”给知识库。这批题有 18 道能在原文中找到答案，5 道故意问资料没有交代的事情。每道正例可以标注多个有效原文短句：只要命中其中任意一段，就算检索到答案，避免把正确的另一处表述误判为失败。

## 2026-10-27 基线

| 指标 | 结果 | 读法 |
| --- | ---: | --- |
| 答案原文块 Top-1 | 9/18 | 第一条检索结果就含有一个标注的有效答案 |
| 答案原文块 Top-5 | 17/18 | 前五条里含有一个标注的有效答案 |
| 无答案题无命中 | 0/5 | 五题都有表面相关的检索结果，不能直接拿它们作答 |

**具体错误比总分更重要：**

- D02 问 Benchmark 数据集在页面上能看什么。前五块含有许多 Benchmark 相关内容，但没有命中标注的“只读展示接入包声明的公开字段”原文块。长文中的重复词把真正答案挤下去了。
- T01、T03、T06、D04、E01、E02、M02 的答案在第 2～4 位；如果只取第一块喂给模型，这些题很可能丢掉关键证据。
- E03 的原文有两处都能说明“生成 Trace 会重新运行 Agent”。最初只标一处，显示为 MISS；我们检查第一条原文确实也支持答案后，把它加入 `also_accept`，现在计为第 1 位。这是在修评测标注，不是调检索算法。
- 5 道无答案题都命中一些词面相近的内容。例如“导出文件的加密密码”会命中 Trace Bundle 导出说明，“自动翻译题目”会命中一个翻译评测样例。**出现搜索结果不代表文档回答了问题。**

## 这说明下一步该做什么

目前仍是本地命令行关键词检索；没有模型回答、证据支持校验或最终拒答能力。下一轮应先检查原文解析和切块：这四篇文档含 HTML 图片标签、长段落和大量近似标题，它们会占用检索块并重复关键词。之后尝试更合适的中文分词或语义检索，逐项和这里的固定基线对比。无答案题要由“证据是否真正支持回答”的判断处理，不能把 BM25 分数硬设成正确率阈值。

这 23 道题是课程团队编写的**开发集**，还没有经过另一位同学的独立复核；它们不等于上游官方题库，也不够证明课程验收质量。B 岗可以从真实页面操作再补口语化问题；A 岗负责保持来源、标注和运行结果可追溯。以后另留一批不参与调参的验收题。
