# 从 0 追上项目进度：A 岗学习路线

适合第一次接触这个仓库的 A 岗同学。你不需要先学完 Python、数据库和机器学习；我们按项目里真实发生的数据流学习，每一步只读少量关键代码、亲手跑一个小实验，再用自己的话解释结果。日常接线和重复代码由 Codex 完成，你重点理解方向、数据如何流动、如何判断它有没有做对。

## 我们到底在造什么

课程最终要的是一个能放进 Agent Insight 网页的知识库问答插件。用户上传资料、提出问题，小助手应从资料中找依据、回答并给出可点开的引用；资料没有答案时要说明不能确定。

当前仓库只做到下面的前半段：

```text
本地目录或网页上传的 MD/TXT
  → 检查文件、读取文字
  → 存入 SQLite，保留原件和版本
  → 把长文切成有来源位置的文本块
  → 本地命令行关键词检索、用题目评测
  → [尚未实现] 依据证据生成回答、引用核验、前端插件、Agent Insight 集成
```

**SQLite** 可以先理解成一个保存在电脑上的数据库文件；**API** 是浏览器和后端约定的请求地址；**文本块** 是长文切出来、仍带有文件名和行号的小段。当前搜到块不代表可以回答，检索分数也不是可信度。

## 学习顺序与过关标准

| 步骤 | 读什么 | 自己做什么 | 跟上这一段的标准 |
| --- | --- | --- | --- |
| 0. 认路 | 本页、`README.md` | 看仓库目录，确认 Python 能运行 | 能指出“代码、测试、课程说明、运行数据”分别在哪 |
| 1. 请求进后端 | [第 1 课](01-backend-foundation.md)，`apps/api/app/main.py` | 跑 `test_health.py`，在浏览器看 `/health` | 能说出浏览器请求如何进入 `health()` 并变成 JSON |
| 2. 文件进数据库 | [第 2 课](02-local-import.md)，`cli.py`、`import_service.py`、`knowledge_store.py` | 建一个测试知识库，导入示例两次 | 能解释 `created`、`unchanged`、版本和原件副本 |
| 3. 网页上传走同一路 | [第 3 课](03-web-upload-api.md)，`api_routes.py` | 在 `/docs` 上传一个示例文件 | 能解释浏览器为什么只能上传用户选中的文件，和 CLI 共用哪一步 |
| 4. 保留出处地拆长文 | [第 4 课](04-text-chunks.md)，`chunking.py` | 列出一个文件的文本块和行号 | 能指出回答引用为什么要用文件、版本、行号 |
| 5. 找资料和测效果 | [第 5～8 课](05-keyword-search.md)、`retrieval.py`、`evaluation.py` | 搜一个问题，跑演示集与 Agent Insight 评测 | 能区分 Top-1/Top-5、词面命中、真正有依据的回答 |

先按表格顺序走。第 5～8 课记录了检索从最初基线到当前两路排序的过程，旧结果是历史对照，并不是当前代码又退回了旧实现。遇到代码读不懂时先找函数**输入是什么、返回什么、是谁调用它**，暂时不用背排序公式。

## 第 0 步：确认你看到的是同一份项目

在 VS Code 中打开 `D:\AAA课程文件\knowledge-assistant`，打开 PowerShell 终端，逐行执行：

```powershell
Set-Location D:\AAA课程文件\knowledge-assistant
git status --short --branch
& .\.venv\Scripts\python.exe --version
Get-ChildItem apps\api\app -Name
```

预期能看到 `main`、Python 3.12 和一组 `.py` 文件。`git status` 不输出文件名表示没有未提交改动；有文件名时先看清是哪一份，不要直接清理。虚拟环境 `.venv/` 是本机依赖，`storage/` 是本机运行数据，两者都不应上传到公开仓库。

现在只需要认出四个位置：

- `apps/api/app/`：后端实际执行的 Python 代码。
- `apps/api/tests/`：用 `pytest` 检查功能的代码。
- `docs/learning/`：逐步解释“为什么这样做”的课程笔记。
- `evals/` 与 `examples/`：公开的评测题、示例资料；实际数据库在被 Git 忽略的 `storage/`。

完成第 0 步后，进入第 1 课。每学完一段，建议用自己的话回答该段的“跟上标准”，再继续下一段；答错时回到实际代码和输出，不靠死记。

## 到哪一步算“赶上当前进度”

你不必独立重写所有模块。能够从一份文件的导入一路讲到文本块、检索结果和评测分数；能够运行测试、看懂常见失败位置；能够说清**当前尚未实现的问答与插件**，就已经跟上 A 岗现阶段开发。之后我们再共同决定模型接入、证据校验与对 B 岗的接口如何推进。
