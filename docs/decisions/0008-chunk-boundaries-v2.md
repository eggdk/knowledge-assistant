# Decision 0008: bounded overlap alignment and explicit chunk rebuilding

Implemented 2026-11-10 after the user approved fixing a real `Trace` → `ace` truncation in generated answers.

The old overlap started exactly 80 characters before the previous chunk's end. In `experiments.md` that landed inside `Trace` and omitted the qualifier `选择已有`. We preserve the 600-character upper limit and source offsets, but change overlap alignment: search backward for a line break within half the desired overlap, then a sentence end within a quarter. If neither exists, avoid starting inside a normal ASCII word where possible. Hard-limit endpoints also move before ordinary ASCII words rather than splitting them. The unbroken-overlimit fallback still splits when no bounded whole-word alternative exists. Zero overlap stays zero.

This is best-effort context preservation, not a guarantee that every paragraph, sentence, list, URL or code block is atomic. Overlap is now approximate. All chunks remain exact contiguous source slices, never fabricated or prefixed with text that has no matching offsets. Source line numbers and non-whitespace coverage are checked in regression tests.

The algorithm version changes from `mdtxt-v1` to `mdtxt-v2`. Existing IDs are not silently reused for different spans. `python -m app.cli chunks rebuild --kb <id>` builds v2 chunks from stored current-version text in one transaction per knowledge base. It preserves document IDs, source hashes, original bytes, version numbers, import times, previous versions and old-strategy chunks. Rebuilding twice is idempotent; a write failure rolls back the entire knowledge-base rebuild. CLI and API retrieval filter to the current strategy, so existing databases need this explicit rebuild (or reimport) after pulling the update.

Validation on pinned fixtures: Agent Insight Top-1 **12/18 → 13/18**, Top-5 **17/18 → 17/18**; demo remains **10/12**, **12/12**; diagnostic answer ranks remain **2, 4, 1**, so Top-5 stays **3/3**. All 5 Agent Insight and all 4 demo negative questions still produce lexical matches. The first broad sentence-alignment experiment reduced Top-1 to 10/18 and was rejected. The retained shorter backward alignment preserves retrieval while restoring the complete retry list item. These are development-set results, not independent quality estimates.

Backend regression: **88 passed, 1 skipped**, including the actual retry source, ordinary/overlong ASCII words, zero overlap, source offsets/line ranges, rebuild history preservation, isolation, idempotence and rollback. The local developer database was backed up with SQLite backup before rebuilding its 5 active documents; all source/version rows and v1 chunk counts were verified unchanged. The runtime backup and databases are ignored by Git. No paid model calls were made for this change.
